`content/case-studies/`. That folder is the source of truth; the site renders
those files directly.

**How to add one:** follow `docs/case-study-process.md`, then save the result
as `content/case-studies/<slug>.md`. The slug must match the entry's slug in
the site data so the page resolves.

Short one-paragraph summaries for entries that *don't* get a full case study
live in `docs/features.md`.
